ERROR 001

Input Source Selection

Issue
The selected input source does not match the active video signal.
Possible Cause
The monitor is set to an input source that is not currently receiving a valid video signal from the connected device.
Recommended Action
Follow the steps below to adjust the input source on your monitor's OSD interface:
  1. Locate the button or joystick on the rear shell or front bezel of the monitor and press it to open the OSD.
  2. Navigate to Port settings.
  3. Select Input signal.
  4. Change to Auto (or select your active port).
