ERROR 003

KVM Function Unavailable

Issue
The KVM function is unavailable because the USB upstream connection has not been established.
Possible Cause
The USB-B upstream cable is not connected between the monitor and the host computer. Without this connection, the monitor cannot route USB peripherals to the intended host through its integrated KVM function.
Recommended Action
Connect a USB-B upstream cable between the monitor's USB-B upstream port and a USB port on the host computer. Verify that the connection is secure and that the host computer recognizes the monitor's USB hub. Once the upstream connection is established, the KVM function should become available.
