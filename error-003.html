ERROR 003

KVM Function Unavailable

Issue
The KVM function is unavailable because the USB upstream connection has not been established. As a result, USB devices connected to the monitor will not work with the host computer.
Possible Cause
The USB-B cable is not connected between the monitor and the host computer.
Recommended Action
Connect a USB-B cable between the monitor's USB-B port and a USB port on the host computer. Verify that the connection is secure and that the host computer recognizes the monitor's USB hub.
