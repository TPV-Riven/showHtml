Display Signal Recovery

Issue
No PC signal. The external monitor remains black.
Possible Cause
Your PC is currently set to project to its own screen only (PC screen only), which disables the external display output.
Recommended Action
Press ⊞ Win + P on your keyboard. When the "Project" panel appears, select Duplicate or Extend to enable the external monitor.

Scenario B: Auto Source Disabled
Issue / Possible Cause
The monitor does not automatically detect the new video signal because the input source is fixed and Auto Source is disabled.
Recommended Action
Use the monitor's joystick to open the OSD, navigate to Port settings → Input signal, and set it to Auto.
